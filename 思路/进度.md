### C6 从机固件烧录
```bash
# 通过 UART (COMx 为 C6 串口号)
python -m esptool --chip esp32c6 -b 460800 --before default_reset --after hard_reset write_flash \
  --flash_mode dio --flash_size 4MB --flash_freq 80m \
  0x0 build/bootloader/bootloader.bin \
  0x8000 build/partition_table/partition-table.bin \
  0xd000 build/ota_data_initial.bin \
  0x10000 build/network_adapter.bin
```

### 架构设计

```
I2S MEMS Mic → ES8388 Codec → I2S → AFE (AEC/NS/VAD/WakeNet) → MultiNet → 回调输出
                                                                    ↓
                                                              唤醒词检测 → 监视窗口
                                                              命令识别   → 监视窗口
```

### 唤醒词列表 (wake_words.h)

| 模型名 | 唤醒词 |
|--------|--------|
| `wn9_hilexin` | 你好乐鑫 |
| `wn9_hiesp` | 嗨 ESP |

### 命令词列表 (wake_words.h)

- 打开窗帘, 关闭窗帘, 停止, 打开灯光, 关闭灯光

### 关键实现细节

- **不触碰联网模块**: msg_bus.c/h 和 config.h 完全未修改
- **AFE 模式**: SR_MODE_HIGH_PERF (高性能), 单麦克风通道 ("M")
- **采样率**: 16kHz, 16-bit 单声道
- **内存**: 使用 PSRAM 分配音频缓冲区 (MALLOC_CAP_SPIRAM)
- **ES8388**: 通过 I2C (GPIO4/5) 初始化 codec
- **I2S 引脚**: BCK=GPIO20, WS=GPIO21, DIN=GPIO22 (避开 SDIO GPIO14-19)
- **容错**: 语音识别初始化失败不影响联网功能运行
